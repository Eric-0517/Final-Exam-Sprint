INTRODUCTION

第一章 數位科技概念

1-3 資料數位化之原理與方法（近五年出１題）

１數位化

定義
類比資料：呈現連續變化的真實資料（ex. 聲波、光波）。
數位資料：
① 從類比資料中，截取接近的離散數據來呈現資料。
② 易儲存、傳送，且抗干擾能力佳。
③ 可將資料加密、壓縮、錯誤檢查（ex. 音訊檔、影像檔）。
數位化：將類比資料轉換成數位資料的過程（ex. 類比數位轉換器）。
(註) 類比數位轉換器(Analog-to-Digital Converter, ADC, A/D)可將類比資料轉換成電腦可處理的數位格式。反之，數位類比轉換器(Digital-to-Analog Converter, DAC, D/A)則是將數位資料還原成類比資料。
數位化過程
步驟１ 取樣 (Sampling)：將連續的類比訊號以分散的週期切割後，取得每個節點的振幅值。
步驟２ 量化 (Quantization)：將分散週期切割的振幅值，各自對應到接近的分散數值。
步驟３ 編碼 (Encoding)：將量化的數值，轉換成電腦能表示的訊號。

２聲音數位化（近五年出０題）

聲音的三要素
音量 (Volume)：單位：分貝 (dB)。聲音的大小，即聲波的振幅。
音調 (Pitch)：單位：赫茲 (Hz)。聲音的高低，即聲波的頻率。
音色 (Tone)：聲音的特色，即聲波的波形，如鋼琴和小提琴彈奏的聲音，各具不同特色。
聲音數位化的過程與範例
步驟１ 取樣 (Sampling)：將音波切割成類比波形訊號。
● 取樣頻率：每秒對聲音的取樣次數，單位為赫茲 (Hz)（人類聽力範圍大約介於20 Hz∼20 KHz之間），取樣率越高，則音質越好。
步驟２ 量化 (Quantization)：將訊號對照各切割點位置標示成數字。
● 取樣位元／取樣解析度：記錄每個取樣所使用的位元 (bit)，取樣位元越多，則誤差越小、音質越好。
步驟３ 編碼 (Encoding)：將數字資訊轉換為電腦能解讀的訊息記錄。
範例：頻寬計算
Ｑ：小雷想替素人歌手的試唱以雙聲道進行錄音，已知取樣頻率44,100 Hz，每個取樣以16 bits表示，取樣時間10秒，試問音訊檔案大小為何？
答案：
音訊檔案大小＝取樣頻率×位元數×聲道數×時間長度
44,100×16×2×10＝14,112,000 bits＝1,764,000 Bytes＝1.68 MB
音訊檔案的格式
未經壓縮（無失真）：
● WAV：Windows的原始音訊格式，檔案大。
● CDA：常用於音樂CD。
破壞性壓縮（失真）：
● MP3：①藉由刪去人難以辨識的部分，大幅縮減檔案大小。②常用於網路音樂。
● WMA：微軟開發，支援串流。
● AAC：比MP3更高的壓縮率，檔案更小，且音質更好。
● OGG：類似MP3的音訊格式，屬於開放式格式。
非破壞性壓縮（無失真）：
● APE：檔案的大小為WAV的二分之一，並能維持良好的音質，壓縮比約為1：3。
● FLAC：檔案較APE大，但兼容性更好，且編碼速度快。
● ALAC：蘋果公司的音訊格式，可壓縮40%至60%。
電子合成樂：
● MIDI：記錄類似樂譜的資料（如音符、調號），檔案小。
(註) 音訊檔案大小：WAV＞MP3＞AAC＞MIDI；音質比較：WAV＞AAC＞MP3。

３影像數位化（近五年出０題）

影像的類型
點陣圖 (Bitmap)：①由像素 (Pixel)構成。②放大呈現鋸齒狀模糊（失真）。ex. 照片、繪畫。
向量圖 (Vector)：①記錄類似數學方程式的資料（如圓心座標、半徑長度等）。②放大呈現依然清晰（不失真）。ex. 美工插圖、工程圖。
影像數位化的過程與色彩對照表
步驟１ 取樣 (Sampling)：將影像以方格切割。
● 解析度：單位為ppi（每英吋中的像素）、dpi（每英吋中的點數），解析度越高（即方格越密），影像品質越好。
步驟２ 量化 (Quantization)：將每格影像方格依顏色標示。
● 色彩深度：記錄每個像素的顏色所使用的位元 (bit)，位元越多，顏色還原度越高。
色彩類型 位元數 能表現的色彩數
黑白 1位元 21=2色
灰階 8位元 28=256色
256色 8位元 28=256色
高彩 16位元 216=65536色
全彩 24位元 224=1677萬色
步驟３ 編碼 (Encoding)：將每格方格轉換為以0與1位元符號標示的二進位訊息記錄。
範例：影像檔案大小與尺寸計算
Ｑ：一張4×6英吋數位影像，解析度72 ppi，以256色儲存，其檔案大小為多少？
答案：影像檔案大小＝總像素×位元數
(4×72)×(6×72)×log2256 ＝ (4×72)×(6×72)×8 bits ＝ 124,416 Bytes ＝ 121.5 KB
Ｑ：一張24位元的全彩影像，尺寸為800×600，請問儲存這張影像需要多少記憶空間？
答案：800×600×24 bits ＝ 800×600×3 Bytes ＝ 1,440,000 Bytes ＝ 1.37 MB
Ｑ：一張800×600的點陣圖，若以200像素/英吋列印時，長寬各是多少英吋？
答案：長：800÷200＝4英吋，寬：600÷200＝3英吋
影像檔案的格式
點陣圖 (Bitmap)：
● 未經壓縮（無失真）：BMP（Windows原始格式，檔案大）、IFF/TIFF（常用於掃描、排版印刷，檔案大）。
● 破壞性壓縮（失真）：JPG/JPEG（1992年發布，支援全彩、高效率壓縮比）、HEIF/HEIC（最新格式，常用於儲存連拍照片）。
● 非破壞性壓縮（無失真）：PNG（支援全彩、透明背景）、GIF（只有256色，支援動畫、透明背景）。
向量圖 (Vector)：
● CDR：CorelDRAW軟體原始檔。
● AI：Adobe Illustrator軟體原始檔。
● DWG：AutoCAD軟體原始檔。
● EPS：常用於排版印刷，檔案大。
(註) CDR、AI、DWG、EPS雖然為向量圖檔，但也可加入點陣圖。

４影音數位化（近五年出２題）

影音的概念
影音是由一張張的圖像所組成，需透過壓縮（編碼）來縮小容量，並且在觀看時解壓縮（解碼）。
影音數位化的過程與範例
步驟１ 取樣 (Sampling)：將影音擷取成單張影像，再將每張影像以方格切割，擷取影像間不同的部份。
● 取樣頻率：每秒擷取影像的次數，單位為fps（每秒框數）、Hz（赫茲），取樣頻率越高，影音品質越好。
● 取樣密度：影像分割成固定像素 (pixel)，取樣密度越高，影像品質越好。
步驟２ 量化 (Quantization)：將影像間不同部份的每格影像方格依顏色標示。
● 位元深度：記錄每個像素的顏色所使用的位元 (bit)，位元越多，顏色還原度越高。
步驟３ 編碼 (Encoding)：透過編解碼器 (Video Codec)將影音壓縮成影音格式。
常見的編解碼器：
● H.263：最初用於視訊會議和視訊電話。
● MPEG-4：用於音訊和視訊的壓縮編碼標準（ex. WMV9、Quick Time、DivX、Xvid）。
● H.264/AVC（進階視訊編碼）：廣泛用於各類網路和系統應用上，包括視訊、廣播及DVD儲存。
● H.265/HEVC（高效率視訊編碼）：新一代視訊編碼標準，有良好壓縮率，並支援8K解析度的影音。
範例：影音檔案大小計算
Ｑ：有一支256色的800×600影音，影格速率10 fps，長度10秒，請問其檔案大小約為多少？
答案：
影格速率指的是每秒播放的畫面數，單位為fps
影音檔案大小＝畫面總像素×位元數×影格速率×時間長度
(800×600)×(log2256)×10×10 bits ＝ (800×600)×8×10×10 bits ＝ (800×600)×10×10 Bytes ＝ 48×106 Bytes ≈ 48 MB
影音檔案的格式
影音檔案是一種容器，它可能包含用編解碼器產生的檔案、多聲道的音效檔案、圖片、影音資訊或字幕等。
影音檔案 副檔名 編解碼器 音效編碼
AVI .avi 所有 所有
FLV .flv、.f4v、.f4p H.264 AAC、MP3
WMV .wmv、.asf Windows Media Video WMA
MOV .mov、.qt 所有 所有
MP4 .mp4、.m4p H.264、MPEG-4、HEVC AAC、MP3
