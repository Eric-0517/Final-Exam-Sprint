考前衝刺

隱私權政策

最後更新日期：2026 年 10 月 24 日

「考前衝刺」是一個提供考試練習、重點整理及個人學習紀錄功能的網站。 我們重視使用者的個人資料與隱私，以下說明網站在使用 Google 登入、 儲存學習紀錄及提供個人中心功能時，如何處理相關資料。

一、網站管理者

本網站名稱為「考前衝刺」，網站網址為 https://eric-0517.github.io/Final-Exam-Sprint/。 網站由ERIC創建及維護。

如需詢問個人資料相關事項，可透過IG聯絡： IG個人頁面。

二、我們會處理哪些資料？

依照使用者使用的功能，本網站可能處理以下資料：

  • Google 登入資料： Google 帳號識別資訊、電子郵件、顯示名稱及個人頭像等， 實際資料以 Google 登入授權及 Supabase Auth 回傳內容為準。
  • 歷次成績： 測驗科目、測驗時間、分數、作答題數及答對題數等， 實際欄位依網站儲存的紀錄而定。
  • 雲端錯題本： 科目、題目識別資訊、題目快照、最近作答答案、累計答錯次數及熟悉狀態。
  • 我的收藏： 收藏題目的科目、題目識別資訊及收藏時間。
  • 未完成測驗： 測驗名稱、科目、已作答答案、目前題目位置及最後更新時間等。
  • 必要紀錄： GitHub Pages、Google 或 Supabase 等第三方服務可能依其運作方式，處理必要的連線、安全及服務診斷資訊。實際蒐集項目依各服務的設定與政策而定。

三、蒐集及使用資料的目的

本網站處理相關資料，是為了提供下列功能：

  • 透過 Google 帳號辨識使用者的登入狀態。
  • 在個人中心顯示使用者的帳號資訊。
  • 儲存、讀取及顯示個人測驗成績。
  • 提供雲端錯題本及錯題熟悉狀態管理。
  • 提供題目收藏及收藏紀錄查詢。
  • 儲存未完成測驗，以便使用者查看相關進度。
  • 維護網站功能、排除錯誤及處理資料存取問題。

本網站不會因使用者登入，就取得其 Google 帳號的密碼。 Google 帳號的驗證由 Google 及相關登入服務處理。

四、資料儲存方式

本網站使用 GitHub Pages 提供網頁服務，並使用 Supabase 處理登入及雲端資料功能。

本網站會透過登入狀態及資料庫權限控制資料存取。 使用者不應將自己的登入帳號或其他個人資料交由他人使用。

五、資料使用對象與第三方服務

為提供網站功能，相關資料可能由以下服務依其功能及政策處理：

  • Google：提供 Google 帳號登入及相關帳號資訊。
  • Supabase：提供登入整合、資料庫及雲端資料儲存功能。
  • GitHub Pages：提供網站頁面的託管與存取。
  • 外部網站：使用者點選成績查詢或其他外部連結後， 相關資料處理方式依該外部網站的規定辦理。

本網站不會因為使用者登入，就將其紀錄公開給其他訪客。

第三方服務政策： Google 隱私權政策； Supabase 隱私權政策； GitHub 隱私權聲明。

六、資料保存期間

本網站會依提供學習紀錄及帳號功能所需保存相關資料。 資料實際保存時間可能受到資料庫設定、服務政策及使用者提出的要求影響。

登出 Google 帳號只會結束目前的登入狀態，不代表雲端成績、 錯題、收藏或未完成測驗會自動刪除。

七、使用者的個人資料權利

使用者得依適用法令，就自己的個人資料提出查詢、閱覽、 複製、更正、停止處理或利用及刪除等要求。 實際權利與適用限制依相關法令及具體情況認定。

如需提出要求，請透過本頁所列的聯絡管道提出， 並清楚說明需要處理的資料類型。 為避免他人冒用身分，管理者可能需要進行合理的身分確認。

如要刪除雲端學習資料，請明確提出刪除要求。 僅從網站登出、關閉瀏覽器或停止使用網站， 不代表資料已經從資料庫移除。

八、未登入時的使用

使用者可以不登入 Google 帳號，使用網站中不要求登入的公開學習功能。 但個人中心及需要帳號識別的雲端成績、錯題、收藏與未完成測驗功能， 可能需要登入後才能使用。

九、資料安全

本網站會依目前的系統架構及可用措施維護資料安全， 並應透過適當的資料庫權限及 RLS 設定限制未經授權的存取。 但網路及第三方服務仍可能存在無法完全預測的風險， 因此無法保證所有服務在任何情況下均不會發生安全事件。

十、未成年人使用

本網站的使用者可能包含學生。 未成年人使用網站及提供個人資料時， 應依其年齡及適用法令，在必要情況下取得法定代理人的同意或協助。

十一、政策修改

本網站可能因功能、資料處理方式或相關法令變更而更新本政策。 修訂內容將公布於本頁，並更新最後修改日期。

十二、聯絡方式

如對本政策或個人資料處理有疑問， 請透過 IG頁面 聯絡網站管理者。
